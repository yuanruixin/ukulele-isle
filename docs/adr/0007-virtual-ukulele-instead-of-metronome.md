# ADR 0007: 虚拟尤克里里（点指板出声 + 录制回放），替换原「节拍器」规划

## 状态

已接受 (2026-09-16)

## 背景

工具页第三张卡片原本是「节拍器（敬请期待）」（从未实现）。用户决定取消节拍器，改成**虚拟尤克里里**：
点指板上的某一格就发出对应的音，支持**录制回放**（这就是需求里的「标记」），并且**弦要有晃动感**。

三处需要定型：

1. **单音怎么发声**。和弦库那套「换谱 + 重试起播」有明显延迟（ADR 0006 实测 150–200ms），
   单音探索时一下一下点，延迟会非常明显。
2. **弦的晃动怎么做**。CSS 动画 vs 逐帧计算。
3. **指板怎么摆**，以及窄屏怎么办。

## 决策

- **发声**：挂载时把**整块指板**（每格 = 一个小节的全音符）一次性交给 alphaTab 解析，
  之后每次拨弦只调 **`api.playNote(note)`**——换谱只发生一次。
- **晃动**：用 **requestAnimationFrame 逐帧算一根被拨动的弦的驻波**，直接写 path 的 `d`，不用 CSS 动画。
- **指板横放**：琴枕在左、品位向右变密（每品 ×0.9455 ≈ 2^(-1/12)，12 品处刚好剩一半）；
  弦从上到下是 **4 弦 G → 3 弦 C → 2 弦 E → 1 弦 A**（同 TAB 谱的弦序，也是低头看指板的顺序）。
- **窄屏**只显示前 7 品（`uke.fretsMobile`）、并把弦间距放大（`uke.rowGapMobile`）；
  谱面数据仍按完整的 12 品生成，**只是少显示几品**。
- **录制回放复用同一条 pluck 通路**：回放时弦照样晃、读数照样跳，听的与看的天然一致。

> 验收后追加的三条（键盘映射、移动端竖置、一屏展示）见 **ADR 0008**，
> 其中窄屏的摆放方式已被推翻：`rowGapMobile` 由 56 改为 **64**，且竖置时指板朝向改为
> **琴枕在上**（本节描述的「琴枕在左」现在只适用于宽屏）。

## 理由

- **为什么 `playNote` 能去掉延迟**：它内部是 `MidiFileGenerator.generateSingleNote(note)`
  → `player.playOneTimeMidiFile(midi)`，只生成**一个音**的 MIDI，不重算整份谱面。
  代价是 `playOneTimeMidiFile` 会先停掉上一个一次性音，所以它是**单音**通路（见「后果」）。
- **为什么余音要写成全音符 + `\tempo`**：`generateSingleNote` 取 `beat.playbackDuration` 当音长，
  所以想让音响 2.2 秒就必须写成全音符、再由 `tempoForRing()` 反推速度——与和弦库同一套换算，
  于是**耳朵听到的余音时长与眼睛看到的晃动衰减时长是同一个数**（`uke.ringSeconds`）。
- **为什么不用 CSS 动画**：晃动的形状取决于「掐在第几品」（弦被按住的点以右才振动）和
  「拨在哪一点」（波腹的位置），CSS 只能放一段与状态无关的固定动画，看不出品位差异。
  逐帧算还顺手实现了「同一根弦再拨一次就重新起波」和「换品后振动段跟着变短」。
- **弦序方向必须显式翻转**（本项目第二个「最容易录反」的地方）：配置与 alphaTex 里
  string 1 = `\tuning` 的第一根 = **最高音弦**，而 alphaTab 解析出的 `Note.string` 1 = **最低音弦**，
  两套编号正好相反，`stringIndexFromNote()` 负责这次翻转，索引键是 `${弦下标}:${品}`。

## 后果

- **是单音乐器**：后一个音会掐掉前一个音的余音（不叠加）。这是 `playOneTimeMidiFile` 的固有行为，
  已明确接受——这一页要的是「点哪响哪」的手感。想要和弦叠加用和弦库；日后真要做复音，
  得开多个 alphaTab 实例（每个实例一份音色库与 AudioContext），代价不小。
- 进这一页仍需约 4.3MB（alphaTab + 音色库），但与歌曲页 / 和弦库**共用同一份 chunk 与音色缓存**，
  从别的页面过来时不再重复下载。
- 录制只存在内存里，刷新即失；上限 `uke.maxRecordNotes` 个音，录满自动停。
- 窄屏只给 7 品是刻意的取舍：12 品在手机上每格不足 20px，手指点不准。
  调整窄屏观感时 `uke.fretsMobile` 与 `uke.rowGapMobile` 要一起看。
- 拨弦时会同时做四件事（发声 / 起晃动 / 更新读数 / 记一笔），都收在页面里的 `emit()` 一处，
  回放也走它——新增手感相关的东西时不要绕开这条通路。
