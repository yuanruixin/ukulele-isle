# ADR 0003: Tailwind + 自定义组件实现 Apple HIG 风格 UI

## 状态

已接受 (2026-09-14)

## 背景

UI 要求现代化、遵循苹果设计语言（毛玻璃、大圆角、大留白、细腻动效）。现成 React 组件库（Naive UI、Arco、MUI）均无原生 Apple 风格；shadcn/ui 可定制但默认风格中性。

## 决策

使用 Tailwind CSS 手写少量自定义组件（卡片、按钮、毛玻璃导航栏等），不引入成品组件库。主题采用浅色 + 深色自动跟随系统外观，CSS 变量驱动。

## 理由

- Apple HIG 质感主要靠细节（模糊、阴影、动效曲线），自定义组件还原度最高，无组件库风格负担。
- 页面与组件数量少（首页 + 详情页），手写成本可控。
- Tailwind 的设计令牌（间距、圆角、色板）便于与站点配置联动调整。

## 后果

- 复杂交互组件（如未来需要的下拉、弹窗）需自行实现无障碍细节。
- 样式质量依赖手写水平，需建立少量可复用的基础组件避免碎片化。
