# ADR 0001: 使用 alphaTex 作为曲谱存储格式

## 状态

已接受 (2026-09-14)

## 背景

网站需要存储、渲染并演奏尤克里里曲谱。候选格式：alphaTex、Guitar Pro 文件 (.gp/.gpx)、MusicXML、自研 JSON 音符数据。

## 决策

所有曲谱以 alphaTex 文本格式存储，由 alphaTab 直接渲染与播放。

## 理由

- alphaTex 是纯文本，手写、修改、版本管理都直观，适合自写《晴天》前奏这类单音指弹谱。
- 原生支持自定义调弦（GCEA 尤克里里调弦）与四弦谱面。
- 无需额外编辑软件（Guitar Pro 需购买/安装），添加歌曲 = 新增一个文本文件。
- MusicXML 对尤克里里指法支持较弱；自研 JSON 等于放弃 alphaTab 的谱面渲染能力。

## 后果

- 曲谱格式与 alphaTab 强绑定；未来若换渲染引擎需迁移谱面。
- 复杂制谱（多声部、装饰音排版）受 alphaTex 语法能力限制，需在实践中验证。
