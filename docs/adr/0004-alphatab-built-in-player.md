# ADR 0004: 使用 alphaTab 内置播放器实现同步演奏与节拍高亮

## 状态

已接受 (2026-09-14)

## 背景

需求包含"同步演奏、高亮对应节拍"。候选：alphaTab 内置 SoundFont 播放器（与谱面天然同步）vs 与原曲真实音频对齐（需手动标注时间轴，且有版权与托管问题）。

## 决策

使用 alphaTab 内置播放器：SoundFont 合成音频播放谱面，启用播放光标与当前节拍高亮，提供速度调节与循环练习能力。

## 理由

- 谱面即音源，同步零成本，高亮精确到节拍。
- 无音频版权风险，无音频托管成本，保持纯静态站。
- 对"学习"场景，可调速的合成音比原曲更实用。

## 后果

- 音色为合成音（尤克里里 SoundFont 近似音色），非真实录音质感。
- 未来若要接入原曲音频对齐，需另做时间轴标注系统。
