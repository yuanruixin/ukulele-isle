# 位图 → SVG 复刻（描摹，不是重画）

## 什么时候用

用户明确要「复刻」「照原样」「不要重新生成」时 —— 包括把参考图直接变成站点资源。
**和「照着风格另画一只」是两件事**：如果用户已经三次否掉你自创的造型，
不要再调曲线了，换到这条路径。

核心承诺：几何、笔触抖动、配色全部来自原图。你只做矢量化和分层，**不加一笔**。

## 一句话流程

```
分色板（从原图量出真实色） → 连通域定位色块核心 → 颜色在最近的两个区域间裁决边界
    → marching squares 取轮廓 → Douglas-Peucker 抽稀 → Catmull-Rom 转三次贝塞尔
```

## 四个坑（全是实测踩出来的，按踩到的顺序）

### 1. 抗锯齿过渡带会自己长成"一层色"

k-means 直接跑在内容像素上，聚类中心会被边缘过渡带拖走 ——
每个灰度台阶自成一簇，描出来是一堆 1px 宽的碎环，**路径体积爆炸且难看**
（实测：一张图 50 KB，其中 24 KB 是一个只有 3800 像素的"灰层"）。

两条对症的修法，都要：
- 只用**局部方差小**的像素（色块内部）去定调色板；
- 更彻底：直接给**显式调色板**（见坑 2），过渡带像素按最近色吸附。

### 2. 调色板要从原图**量**出来，不要猜

`#7f7f7f` 恰好是黑白的**中点灰度(127.5)**，看起来就像"过渡带"；
但同一张图里它也可能真是灰笔的颜色。**别推理，量。**

```python
# 中间调连通域：既非近黑也非近白 = 灰笔 / 彩色 / 过渡带
mid = content & (lum > 45) & (lum < 230)
lab, n = scipy.ndimage.label(mid, np.ones((3, 3)))
# 每个连通块报 area + 均值色 + bbox：
#   细长 bbox（跨度上百像素、面积却很小）= 贴着轮廓的过渡带
#   紧凑 bbox + 独立成形               = 真笔画
```

再对可疑区域直接取主色直方图（`(rgb//16)*16` + `np.unique(..., axis=0)`）钉死数值。
实测四张参考图量出来的结果见 `references/measured-palettes.md`。

### 3. 只看"最近的种子"会把线画胖、把细缺口填死

**几何最近 ≠ 正确的边界。** 黑线两侧的抗锯齿像素，几何上离黑种子更近，
全判给黑 ⇒ 每条线凭空胖 2px；窄白缝（比如猫耳与头之间那道缺口、
四道平行细纹之间的缝）连白色种子都长不出来，被两侧的黑直接填死。

正确做法是**两段式**：
1. **几何定归属** —— 每个像素算出最近的两个竞争区域 A、B
   （各自到"该类种子"的距离，用 `distance_transform_edt(seed != k)`）；
2. **颜色定边界** —— 在 A / B 之间按 RGB 距离裁决。

反过来的"纯颜色最近"也不行：黑↔白的过渡带中段灰，恰好落在灰笔颜色附近 ⇒
**每条黑线镶一圈灰边**。限制成"只在最近的两个区域里选"，灰层就跨不过黑线了。

### 4. 放大倍数必须同步放大的，是**观察窗口**不是容差

`--scale` 先 LANCZOS 放大再处理，是为了救细笔画（几道平行细纹、1-2px 的缝，
原尺寸下播种时凑不出"内部"，会糊成一整块）。

但判定"局部平坦"的窗口如果还是 3×3，在 3 倍图上只等于**原始 1 像素** ——
放大后的抗锯齿带内部反而变平滑，被误判成色块内部，全播成种子。
实测：一张图的粉色层从应有的 950 像素炸到 4238 像素。

⇒ **`win = 3 * scale`**，并且 `--tol`（抽稀容差，原始像素单位）与
`--min-area`（`× scale²`）、`--pad`（`× scale`）都要跟着换算。

## 验证

**不要靠眼睛判断线宽**。量：

```python
# 原图按"离线色更近还是离底色更近"划分（与描摹口径一致），对比复刻的分层像素数
mid = (line_lum + 255) / 2
n_orig = (content & (lum < mid)).sum()
```

实测四张：偏差 −5.8% / 0.1% / −2.9% / −12%，即**线宽客观吻合**。
视觉上仍会觉得复刻"重"一点 —— 那是硬边 vs 软边的观感差异，
是矢量化必然的结果，也正是要的效果，**不要去加负向补偿**。

体积/保真平衡点：`--tol 1.8`（`1.0` 更准但大 60%）。

## 输出约定

- 每个色层一个 `<path fill="#…" data-c="#…" data-role="…">`，`fill-rule="evenodd"`
  天然处理孔洞（一个 `d` 里的多个子路径按嵌套奇偶填充）。
- 层序按**亮度降序**（亮在下、深在上），回补描边时才不会互相啃。
- `data-c` = 原始色号，`data-role="base"` = 最亮那层（身体/纸）。
  站点侧可用 CSS 按色号重映射 → 同一份 SVG 同时服务浅色与深色主题。

### 深色主题换色（别用简单的"明度取反"）

直接翻转明度会把米色身体变成浑棕。正确的两条规则：

- `data-role="base"` 那层 → 深色舞台色（如 `#26282d`）
- 其余层 → **保色相**，`L' = 0.16 + (1 - L) * 0.72`，`S` 不变

实测这样在深色底上白线稿、彩色点缀（腮红、蓝 Z）都成立。
