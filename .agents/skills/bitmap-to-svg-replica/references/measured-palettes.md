## 量色时的关键观察

**listen 的中间调连通域**（`mid = content & 45 < lum < 230`，3×3 连通）:

```
  1274px  #c3c3c3  bbox 272,274–335,316   ← 紧凑 63×42，是额头斜纹（浅灰）
  1078px  #8d8d8d  bbox 151,223–192,271   ← 紧凑，是音符（中灰）
   688px  #8d8d8d  bbox 202,158–234,199   ← 紧凑，另一个音符
   664px  #838383  bbox 206,249–319,438   ← 细长跨 113×189，是过渡带
   467px  #929292  bbox 323,315–375,447   ← 细长跨 52×132，是过渡带
   349px  #c7c7c7  bbox 260,406–285,424   ← 紧凑，是底部蝴蝶结（浅灰）
```

**判据**：`面积 / bbox 面积` 比值低 + bbox 跨度大 = 过渡带；紧凑成形 = 真笔画。

**监听单张图的 `贴边率`**（一个簇里贴着别的簇的像素占比）也有用：
平坦区内部接近 0，过渡带接近 1。但**阈值要小心** ——
`#7f7f7f` 的贴边率只有 0.65，看着不像过渡带；实际它确实是灰笔颜色，
而黑白中点 127.5 也恰好落在这附近。这条规则只能当**辅助**，最终以直方图取色为准。
